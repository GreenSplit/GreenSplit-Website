A modern speedrun timer.

GreenSplit is a fast speedrun timer written in C++ & QT with modern features, LiveSplit file compatibility, and natively supports Windows, Linux, and macOS.

Features

Core features at a glance.

LiveSplit compatible

Import your livesplit settings, and open LiveSplit .lss splits and .lsl layouts natively.

LiveSplit server compatible

Works natively with anything that connects to a LiveSplit server.

Native therun.gg support

Integrates natively with therun.gg. Automatically uploads runs, and keeps track of stats.

Branches

The first speedrun timer with split branches. Run a category where the level order can differ? Branches solve this problem.

OBS & Twitch Integrations

Connect GreenSplit to OBS through WebSockets, and connect your Twitch account, to create unique interactions!

True Transparency

Make your splits background fully transparent. No more fiddling with annoying chroma keys.

Generate Comparisons

Set a target time, and generate a comparison for it. Weight the splits yourself, or automatically from averages.

Discord Rich Presence

Automatically show your discord friends what category you're currently running, and if you're ahead! or behind :(

Python Plugin API

Have a feature idea that doesn't exist? Make a plugin for it! Featuring a fully featured Python API, to easily extend the functionality of GreenSplit.
